# Southern Water Infrastructure Transparency Tool

An interactive map connecting storm overflow data to public procurement records for Southern Water's network across Kent, Sussex, Hampshire and the Isle of Wight.

## What this shows

- **1,031 overflow sites** with spill hours from the Storm Overflow Portal
- **233 catchments** with aggregated environmental data
- **119 verified contracts** from Find a Tender government notices
- **42 site-level procurement links** traced via press releases and project announcements

## Files

- `index.html` — Public-facing transparency tool (editorial, shareable)
- `dashboard.html` — Procurement intelligence dashboard (commercial)
- `graph_with_micro_procurement.json` — Complete network graph
- `data/` — Supporting datasets and source records

## Data sources

- [Storm Overflow Portal](https://www.southernwater.co.uk)
- [Find a Tender](https://www.find-tender.service.gov.uk) (UK government procurement notices)
- [data.gov.uk](https://data.gov.uk) (daily XML notice archives)
- [Water Projects Online](https://waterprojectsonline.com) (case studies)
- Press releases from Southern Water, Kier, Costain, Galliford Try and others

## Methodology

Every contract value links to its source document. Where data could not be verified from public records, it is marked as such. Framework call-offs and internal work orders may not be reflected.
